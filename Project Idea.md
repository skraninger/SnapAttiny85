# Project Idea

Create an ATTINY85 based toy for a child that can play music, has touch and variable resistor controls, and can light up an led strip with 8 neopixels with variable patterns.

### Hardware

ATTINY85 chip where 2 pins are used for touch controls, 1 pin is used for a variable resistor, 1 pin is used to for the neopixel strip, and 1 pin is used to output music

## Music to Output

Convert music to format that can be used in the music player. Allow a touch button to switch songs:

- Bluey Theme
- Baby Shark
- Can't stop the feeling - Just the chorus
- Dynamite by BTS - One verse

### Source Code

Program using Arduino for ATTINY85 chip.

### Possible ATTINY85 Pins to Use

The following are suggestions for the pins to use. If there is a better selection, they can be changed.

- Touch in - Pin2, Pin3
- ADC in for variable resistor - Pin7
- Led strip - Pin 6
- PWM out for music - Pin 5
